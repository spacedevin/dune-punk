# Changelog

## 0.1.0

- Initial release: four Daemon 2.0 variants (Daemon, Netrunner, Arasaka, Samurai) with full
  Dune chrome — chamfered frame brackets, cut-corner segments and tabs, neon hairline cards,
  scanline canvas, HUD motion.
- Dune Punk Icons: cut-corner hex-badge file and folder icon theme.
- Dune Punk Circles: monochrome cyan ring icon theme after Daemon-Icons.
- Daemon variant matched to the Daemon 2.0 KDE packages: red title band with `#070D19` ink type
  and controls, Konsole ANSI colors, and a restrained chrome palette: red outlines, pale `#B2CCD6`
  type, slate-teal `#355D65` fills for active states. Chrome follows the Kvantum widget shapes: a
  dark toolbar under a thin red Aurorae edge, title-bar groups and status items drawn as 1px red
  frames chamfered top-left/bottom-right with solid corner ticks, cyan-outlined hover/active rail items.
- Typography follows Daemon: Rajdhani in mixed case (no forced uppercase), system font fallback.
- All variants: outlined buttons (dark fill, frame border), frame-colored input borders, accent
  focus ring, frame-colored progress bar, teal scrollbar thumbs, neon window glow.
